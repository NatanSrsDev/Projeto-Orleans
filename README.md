# Casa Orleans – Sistema de Gestão para Casa de Repouso

**Projeto acadêmico** desenvolvido para gerenciar informações de uma casa de repouso para idosos, utilizando **HTML, CSS e JavaScript** no frontend e **PHPMyAdmin** para o gerenciamento do banco de dados.

---

## 📌 Sobre o Projeto

A **Casa Orleans** é um sistema web simples, criado para facilitar o cadastro, consulta, atualização e exclusão de informações de idosos e funcionários em uma casa de repouso. O projeto foi desenvolvido como parte de um trabalho acadêmico, com foco na aplicação prática de conceitos de **CRUD** (Create, Read, Update, Delete) e manipulação de banco de dados.

---

## 🛠 Tecnologias Utilizadas

| Tecnologia      | Descrição                          |
|-----------------|------------------------------------|
| **HTML5**       | Estrutura das páginas web          |
| **CSS3**        | Estilização e layout responsivo    |
| **JavaScript**  | Validação de formulários e interatividade |
| **PHPMyAdmin**  | Gerenciamento do banco de dados MySQL |

---

## 🔧 Funcionalidades Principais

- **Cadastro de Idosos**: Inclusão de novos residentes com dados pessoais e médicos.
- **Cadastro de Funcionários**: Registro de colaboradores da casa de repouso.
- **Consulta de Informações**: Visualização de todos os registros cadastrados.
- **Atualização de Dados**: Edição de informações de idosos e funcionários.
- **Exclusão de Registros**: Remoção de registros do sistema.

## 📝 Observações

- Este é um projeto acadêmico e não possui autenticação de usuário ou medidas avançadas de segurança.
- O backend é gerenciado diretamente pelo PHPMyAdmin, sem uso de linguagens de programação backend como PHP ou Node.js.
